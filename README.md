# 🎬 MovieIQ - AI Powered Movie Success Prediction Dashboard

## 📌 Project Overview

MovieIQ is an AI-powered Movie Success Prediction Dashboard developed using Python, Machine Learning, and Streamlit.

The application predicts whether a movie is likely to be successful based on features such as budget, popularity, runtime, and average rating. It also provides interactive data analysis, visualizations, and model performance metrics.

---

## 🚀 Features

- 🎯 Movie Success Prediction
- 📊 Interactive EDA Dashboard
- 📂 Dataset Overview
- 🌍 World Map Visualization
- 📈 Model Performance Analysis
- 📉 ROC Curve & Confusion Matrix
- 📥 Download Filtered Dataset
- 🎨 Modern Streamlit User Interface

## ▶️ How to Run

### 1. Clone Repository

```bash
git clone https://github.com/yourusername/MovieIQ.git
```

### 2. Install Libraries

```bash
pip install -r requirements.txt
```

### 3. Run Application

```bash
streamlit run app.py
```
